# Used by the Dockerfile and CI as a *constraints* file: pyproject.toml still
# declares what the project needs, and this file decides which version of each
# arrives. Without it, every image rebuild and every CI run re-resolved lower
# bounds to whatever was newest that day, and on 2026-09-30 that meant
# SQLAlchemy 2.1.1 in the containers against 2.0.52 under test, and traces from
# those images carried no database spans until they were rebuilt on these pins.
#
# Regenerate deliberately, and only from an environment the full suite has just
# passed in:
#
#   make lock
#

# the same version on a laptop and in CI, so `measured_by.*` stops moving on its
# own.
